## Core Features:

- Resources
    - Mothers should get recommended resources by workers or based on their profile
    - Resource tracking and follow-up feature
- Forms
    - Ability to send out and fill out forms, and save results to the database per user
- Daily Tasks/Check In
    - Sort of like finch with self-help
    - Admins can assign daily tasks
- Store and Credit System:
    - Mothers should gain credits by attending events, watching videos, etc and receive credits
    - You can use your credits to get rewards or resources
- Self-Care
    - Sort of like Finch where mothers can check-in daily and do personal self-care routines

## 10/2 UI Prototype Meeting

### User Side:
- **Full-Screen Notifications:** Notifications are a big part of the app, they should be a little more urgent than the small notification icon at the top. Maybe a full screen notification when you open the app
- **Resource Reviewing:** Add a good system for user resource reviewing (our vision is that admin see this, but probably not users)
- **Pre-populated forms:** Add more to the forms page, some of which are auto-completed
- **Resource Recommendation:** Counselor recommendation section, resources viewed/searched recently
- **Mother Profile:** Add more fields, figure out what fields are relevant

### Admin Side:
- **Care Workflow:** Rather than "stable, watch, new, etc." show the admin the smiley faces that the mothers fill out
- **Resource Recommendation:** the flow needs to be a little more intuitive to recommend a resource to a mother
- **Combine navigation tabs:** Resource and resource catalog should be 1 tab, forms and forms builder 1 tab
- **Form Builder:** 
    - Make it obvious to the form builder that they can pre-populate a question response
    - Make form buidler full page when you click "new form"
    - Get rid of "form templates" and just have it list your previous forms with the option to edit + make a copy
- **New Resource Setup:** add ability to set a follow-up duration for a specific resource
